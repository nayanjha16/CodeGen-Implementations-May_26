# ============================================================================
# CodeGen Capstone — Python dependencies
# Tested against Python 3.10 / 3.11 on Google Colab (CUDA 12.x runtime)
#
# Every package below (except torch, see note) is pinned to an EXACT version
# captured via `pip freeze` from a Colab session that ran the full pipeline
# successfully end to end (2026-07-20). This is deliberate: every environment
# break in this project so far (numpy, pandas, bert-score/transformers) came
# from `pip install -r requirements.txt` silently resolving unconstrained
# packages to "whatever's newest on PyPI today" -- which drifts forward on
# its own between sessions even when nothing in this repo changes. Exact
# pins freeze the environment so "Run all" installs the same thing today,
# next week, or next semester. To deliberately upgrade something, bump its
# pin here, re-run the full test suite, and verify a real Colab pass before
# committing.
# ============================================================================

# --- Core ML / DL ---

# build tied to its own CUDA runtime (this session's was "2.11.0+cu128", a

# risks forcing pip to fetch a mismatched build and breaking GPU support
# outright on a future Colab image with a different CUDA runtime. Leaving it
